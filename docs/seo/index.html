一、SEO 到底是什么

SEO 的本质：让网页更符合搜索引擎的规则和用户需求，从而获得更高排名和更多自然流量。

要理解 SEO，先要知道搜索引擎怎么工作 —— 三步：

步骤做什么卡住会怎样
爬取派出机器人（Spider）到互联网抓取网页爬不到 → 内容根本不存在
索引把抓到的网页整理、分类，存进自己的数据库收录不了 → 搜不到
排名用户搜索时，从库里找出最相关的页面按算法排序排名太低 → 看不到

所以：爬不到、收录不了、排名太低，用户就看不到你的内容。SEO 的所有动作都围绕这三步。

二、SEO 优化原理（对应上面三步）

目标具体怎么做
提高爬虫可访问性确保网站能被顺利抓取：没有死链、没有 403 错误、没有 JS 阻拦
提高收录率网页内容结构清晰、Meta 信息完整（标题 / 描述 / 关键词）
提高排名关键词优化、页面体验优化、内容质量提升、外链建设 —— 让搜索引擎觉得你"值得推荐"

三、SEO 四大核心原则 ★重点

原则具体含义
相关性页面内容必须精准对应搜索意图，围绕关键词展开
权威性域名权重高、外链质量好；被越多权威网站推荐，越被信任
用户体验网速快、界面友好、内容易读、广告少、用户停留时间长
技术合规HTML 结构规范、使用 SSL、适配手机端、Schema 结构化数据正确
面试时如果能说出「相关性 / 权威性 / 用户体验 / 技术合规」这四条，比背一堆工具名有用得多。

四、站内优化（11 项）

优化项具体做法
关键词研究确定目标关键词、长尾词、布局计划
标题优化（Title）页面标题含关键词，同时要能吸引点击
描述优化（Meta Description）描述包含关键词，诱导用户点击
URL 优化简短、包含关键词、结构清晰
正文内容优化高质量原创内容，合理插入关键词（堆砌会扣分）
H 标签结构用 H1 / H2 / H3 划分清晰的逻辑层次
内链建设页面之间合理互链，增加权重传递
图片 SEO图片加 alt 标签、压缩体积、快速加载
移动端适配响应式设计，适合手机访问
网站地图（Sitemap）生成 XML Sitemap 提交给搜索引擎
Robots.txt合理允许或禁止搜索引擎抓取某些页面

五、站外优化（6 项）

优化项具体做法
外链建设（Link Building）找高权重网站、媒体、论坛做反向链接
社交媒体推广LinkedIn、Twitter、Facebook 等提升曝光
品牌曝光品牌提及（Brand Mention）即使不加链接也加分
内容合作Guest Post、联合发布文章、交换资源
行业目录提交提交到相关行业目录站或黄页
媒体发稿新闻稿、行业报道，增加权威背书
⚠️ 课件这里有个笔误：站外优化下面写的还是「主要是网站内部的优化，让页面更容易被爬虫抓取」—— 那是站内的定义。站外的目标是「获得外部推荐与权重传递」。

六、技术 SEO（8 项）

优化项具体做法
HTTPS 安全协议启用 SSL 证书
网站速度优化图片压缩、CDN 加速、减少 JS
错误页面修复404 页面、301 重定向、修复死链
结构化数据（Schema）让搜索引擎更好理解内容（评分、FAQ 等）
分页处理rel="next" / rel="prev" 正确使用
国际化 SEO多语言站设置 hreflang
Core Web Vitals优化 LCP、FID、CLS（Google 排名因子）
日志分析检查爬虫行为，排除抓取问题
⚠️ 一个更新点：课件写的是 LCP / FID / CLS，但 Google 已在 2024 年 3 月用 INP 取代 FID。面试说「LCP / INP / CLS」更准。

七、SEO × AI：能做什么

  1. 批量写内容 / 提炼内容
  • ⚠️ 关键提醒：不能纯用 AI 生成，必须加人工编辑 + 润色，否则容易被 Google 判定为机器文。
  1. 智能外链建设（最费时的部分，AI 价值最大）
  • 自动挖掘潜在友链网站列表
  • 生成个性化的外链 pitch 邮件
  • 快速撰写 guest post（访客文章）
  • 效果：外链拓展更快、可规模化

八、附：拉新渠道怎么评估（同一节课的另一部分）

二维判断：客户价值 × 获取成本

            获取成本低
                 ▲
                 │      ● 你最理想的渠道
   高流失 ◀──────┼──────▶ 高留存
                 │
            获取成本高
  • 横轴：客户价值（左＝高流失，右＝高留存）
  • 纵轴：获取成本（上＝低，下＝高）
  • 理想渠道 = 右上角：获取成本低 + 用户留存高

用法：渠道不只看"能不能拉来人"，还要看"拉来的人留不留得住、每个用户花多少成本"。只看拉新量不看留存成本，很容易把钱烧在左下方的渠道上。
